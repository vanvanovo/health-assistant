## 三、P10 加固(约 1~1.5 天)

### 3.1 Redis 接入(冻结版:只做"真用"的三件事)

| 用途 | 场景 | 键/过期 | 降级 |
|---|---|---|---|
| 看板聚合缓存 | overview/trends/radar/heatmap 重复请求 | `cache:dash:{name}:{date}` / 60s | Redis 不可用 → 直查(透明) |
| 路由缓存 | 同一句话短时重复问 | `cache:intent:{sha1(text)}` / 300s | 同上 |
| 写操作短锁 | 并发打卡同一计划项 / 并发保存计划 | `lock:checkin:{item_id}` / 10s,wait 2s | 拿不到锁 → 返回忙提示(不阻塞) |

- 启用:`docker compose --profile v4 up -d redis`(:6381);代码走 `core/cache.py`(封装 get/set/lock,失败静默降级)
- 纪律:不做发布订阅/复杂指标,**够用即可**(面试口径:"按需引入,不做过度设计")

### 3.2 容错收口与参数统一(对齐面试口径)

- 超时/重试统一从配置读:LLM 重试 3 次(1s/2s/4s)、MCP 5s、A2A 15s、调度任务单任务失败互相隔离(已有)
- 补**:LLM 主备切换指标日志**(切换次数/最近切换时间,`/health` 可见?——放结构化日志即可)
- 补:Redis 宕机 / PG 慢查询 / RAG 关停 三类降级用例(有的已覆盖,补齐 Redis + 慢查询话术)

### 3.3 用例补齐(离线 ≥10 新增)

- cache 封装:命中/未命中/Redis 异常降级(monkeypatch)
- 写锁:并发打卡同一项只有一次写入(模拟)
- 幂等:调度任务重跑(已有)+ 打卡重复提交(已有)交叉回归
- 隐私:日志不含体重/饮食明文(抽查 logging 输出断言不含敏感字段)

### 3.4 隐私与安全清单(逐条打勾)

- [ ] `.env` 不在 Git(已验)且公网演示前**轮换 Key**(你确认)
- [ ] 日志脱敏:健康数值不落日志(只落 id/状态)
- [ ] 公网演示:仅演示账号 + 演示数据;注册关闭
- [ ] CORS 白名单;JWT 密钥独立;MCP Key 独立
- [ ] 依赖清单锁定(requirements 已锁)

### 3.5 验收

- `scripts/check_cache.py`(真实链路:缓存命中省时对比 / Redis 关停透明降级 / 写锁并发)
- 离线新增 ≥10;E2E 保持全绿;文档《p10_验收记录》

## 四、P11 交付(约 1.5~2 天)

### 4.1 Docker Compose 一键起(本机全功能版)

- 镜像:`health-backend`(gateway 与 rag-agent 共镜像不同入口)+ `frontend`(nginx 托管 dist)+ 复用 `postgres(pgvector)`、`redis`
- compose 服务:postgres / redis / gateway / rag-agent / frontend;healthcheck + depends_on;卷:pgdata
- 首次初始化:容器启动跑 `init_db.py`(幂等);演示数据与知识库:入口脚本按开关执行(`SEED_DEMO=true`、`BUILD_KB=true`)
  - **RAG 嵌入模型体积 2.1GB**:本机版挂载宿主模型目录只读;云端版见 4.3
- 验收:`docker compose --profile v4 up -d` 后,浏览器经 nginx(:8080)完成 3 个场景;`docker compose logs` 无错误

### 4.2 演示脚本与录屏(对齐方案 §1 十场景)

- `docs/演示脚本.md`:十场景逐条 = 输入 + 期待画面 + 台词(参考 out 两个项目的演示脚本格式)
- 录屏由你出镜/配音;**一键复原**命令写进脚本(`python scripts/gen_demo_data.py` + 清 checkpoint)
- 可选:OBS 录屏 5~8 分钟;面试现场也可直接跑本机全功能版

### 4.3 云端轻量版(2C2G,可裁剪并顺延)

- 需要你提供:服务器 IP / SSH 方式 / (可选)域名;未提供则**云端延后**,不阻塞其他交付
- 轻量方案:
  - 服务:gateway + postgres + redis(不跑 rag-agent;或 rag-agent 用 API 嵌入)
  - 嵌入:切 **API embedding**(配置 `EMBEDDING_PROVIDER=api`,百炼/硅基流动兼容口)或预导出 kb 向量导入(本地 build → 云端只读)
  - 演示数据只读保护:关闭写接口?不——保留完整功能 + 仅演示账号
  - Nginx 反代 + HTTPS(域名有则上 Let's Encrypt;无则 IP + 端口)
- 验收:P11 时按服务器实测填数(延迟/内存占用)

### 4.4 文档与数字汇总

- README 顶部:一句话定位 + 架构图(引用方案图)+ **实测数字表**(一次汇总所有可复现指标)
- `docs/` 索引更新(方案 / V1–V4 计划 / p0–p11 验收 / 评测报告 / 演示脚本)
- 纪律复核:所有"【待实测】"处填实或删除

### 4.5 简历口径与面试卡

- `docs/简历口径与面试卡.md`:
  - 简历项目描述 3~4 条(量化:闭环/多 Agent/评测数字/部署)

  - 高频追问 10 问(为什么 LangGraph、为什么 A2A + MCP 混合、为什么 pgvector 不用 Milvus、双模型容灾、闭环如何调计划、安全边界怎么做、评测怎么设计、Windows 异步坑、Redis 真用在哪、三项目如何区分)
