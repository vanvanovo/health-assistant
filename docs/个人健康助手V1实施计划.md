### 4.2 表结构 `scripts/init_db.py`(幂等 DDL,参考 EduAgent `db/migrations.py`)

- 演示账号 `health-demo` + 默认画像(目标:减脂;器械:哑铃+跑鞋;提醒时间 20:00/21:30)。

## 六、P3 记录 / 分析 / 计划 三 Agent(约 1~1.5 天)

### 6.1 `backend/agents/common`

- `state.py`:三张图的 State 定义(消息、槽位、结果卡片、thread_id)。
- LLM 节点统一走 `core/llm.py`;节点 prompt 从 health-planner 迁移改写。

### 6.2 三张 LangGraph 图

| 图 | 节点链 | 要点 |
|---|---|---|
| 记录 recorder | `extract`(LLM 抽取)→ `validate`(范围/白名单/日期)→ `upsert`(MCP)→ `confirm`(卡片) | 缺关键字段 → 返回追问(INPUT_REQUIRED 语义,非失败);日期注入"今天"防相对日期错(R1) |
| 分析 analyst | `collect`(规则统计)→ `anomaly`(规则检测)→ `interpret`(LLM 解读)→ `format`(统计卡) | 统计口径与看板共用同一函数;LLM 只解读不造数;异常信号供预警复用 |
| 计划 planner | `context`(近 30 天 + 完成率 + 体感)→ `adjust`(基础调档:疲劳 → 降强度)→ `generate`(LLM,硬约束只引用给定数据)→ `save`(MCP 版本化)→ `format` | 出差/事件重排、画像注入放 V2 P6 深化;本阶段先把"完成率/体感 → 难度档"跑通 |

### 6.3 测试 `tests/`(全 mock LLM,离线)

- 迁 health-planner 种子:记录 UPSERT/追问/非法值;统计口径边界(空区间/单日/跨月);计划生成约束。
- 新增:幂等重复提交;调档规则单测(阈值边界)。
- 命令:`pytest -q`;目标 V1 阶段 ≥20 用例全绿。

**门禁**:三张图直连可跑(`scripts/check_agents.py`);pytest 全绿;日志有完整链路。

## 七、P4 Router + SSE + 前端初版 + 打卡(约 1~1.5 天)

### 7.1 Router(`backend/core/router.py`)

- 规则前置:问候/感谢/帮助/快捷打卡口令模板直答(零 Token)。
- LLM 意图 JSON:`{intents, slots, need_clarify, clarify, confidence}`;意图枚举 7 类(record/checkin/analyze/plan/diet/knowledge/out_of_scope;V1 实做前 5 类,diet/knowledge 路由到"V2/V3 上线"话术占位)。
- 追问 ≤2 轮;超限/越界 → 兜底话术 + 引导。
- 多意图 V1 串行处理再汇总。

### 7.2 API 与 SSE

- `api/v1/chat.py`:`POST /api/v1/chat/stream`(SSE:routing / progress / token / card / meta / done;卡片:record_confirm / stats / plan)。
- `api/v1/auth.py`:JWT 登录(演示账号);`api/v1/dashboard.py`(overview/trends);`api/v1/plans.py`、`checkins.py`(表单打卡,与对话同链路)。

### 7.3 前端(从 cs-platform 拷贝裁剪)

- 页面:登录 + 对话页(意图卡/记录卡/统计卡/计划卡/追问气泡,SSE 复用 `useSSEChat`)+ 看板初版(指标卡 + 多轴趋势图,ECharts)+ 计划打卡页(周视图 + 打卡按钮 + 完成率)。

### 7.4 意图评测(冷启动)

- 评测集先 60 条(正常/模糊/越界/多意图四类);`scripts/eval_intent.py` 输出准确率/槽位抽取率/混淆矩阵(【待实测】跑完填数)。

### 7.5 V1 最终验收(演示脚本逐条录像)

| # | 场景 | 断言 |
|---|---|---|
| 1 | “今天跑了 5 公里,体重 68.2,睡了 7 个半小时,有点累” | 确认卡 + 落库;重复提交幂等 |
| 2 | “今天跑了 5 公里”(缺体重) → 追问 → 补全 | 追问合规、补全后入库、绝不编造 |
