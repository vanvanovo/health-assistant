## 过程中发现并修复(面试素材)

1. **Windows + psycopg 异步不兼容 ProactorEventLoop** → 必须在事件循环创建**之前**切 Selector;而 `-m uvicorn` 在导入 app 时循环已建好 → 新增 `run_server.py` 入口(先设策略再起 uvicorn)。
2. 主图 dispatch 分支漏把用户消息写入状态 → 多轮历史缺 user 侧;补上后多轮测试通过。
3. 「未来事件」语义:下周才开始的出差**不会**出现在今天的事件列表(有效期过滤正确);验收断言改为按生效日查询,并额外验证"未生效不出现"。
4. **评测边界抖动**:「下周要出差…」是否额外输出 memory 在两次运行间左右横跳 → 评测脚本支持 `expected_any` 等价口径(2 条),不用不稳定的用例假报数字。
